# courierApp — Yetir

On-demand courier delivery platform for Azerbaijan (`yetir.az`).

| Part | Folder | Stack |
|---|---|---|
| Frontend (customer website) | `frontend/` | Next.js 14, React 18, TypeScript, Tailwind CSS |

## Run the frontend

```bash
cd frontend
npm install
npm run dev      # http://localhost:3000
```

Routes and placeholder data are described in [`frontend/README.md`](frontend/README.md).
